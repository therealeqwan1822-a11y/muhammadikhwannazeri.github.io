1. Vision Pipeline Architecture

The Ocular AI architecture bridges edge microcontrollers with real-time host-side Python inference engines to achieve smooth camera telemetry and sub-50ms feedback loops.

  • Video Stream Ingestion: Captures video frames over an HTTP/RTSP stream from an ESP Wi-Fi camera module, buffering frame queues to eliminate jitter.
  • Feature Extraction: Executes lightweight Mediapipe and OpenCV landmark neural networks to extract spatial matrix coordinates without heavy GPU overhead.
  • Telemetry & Automation Control: Translates spatial tracking vectors into action triggers sent back to peripheral actuators or logging dashboards.

3. Inference Engine Script (Python / OpenCV)

Repository Code 
# ====================================================================
# Project: Ocular AI Vision Inference Pipeline
# Author: Muhammad Ikhwan Bin Nazeri
# Frameworks: OpenCV / Mediapipe / ESP WiFi Stream
# ====================================================================

import cv2
import time
import numpy as np

# ESP32-CAM Wi-Fi Stream Endpoint
stream_url = "http://192.168.1.100:81/stream"
cap = cv2.VideoCapture(stream_url)

prev_frame_time = 0

while cap.isOpened():
    ret, frame = cap.read()
    if not ret:
        print("[ERROR] Camera stream disconnected. Retrying...")
        break

    # Spatial Feature Processing
    h, w, c = frame.shape
    rgb_frame = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)

    # Frame Rate (FPS) Calculation
    new_frame_time = time.time()
    fps = 1 / (new_frame_time - prev_frame_time) if prev_frame_time != 0 else 0
    prev_frame_time = new_frame_time

    # Display Overlay
    cv2.putText(frame, f"FPS: {int(fps)}", (20, 40), 
                cv2.FONT_HERSHEY_SIMPLEX, 0.8, (0, 255, 0), 2)

    cv2.imshow("Ocular AI Vision Feed", frame)
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

cap.release()
cv2.destroyAllWindows()
