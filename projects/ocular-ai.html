2. 5-Stage Inspection & Trust Pipeline

STAGE 01

Distance Gate

Evaluates bounding box spatial ratio to enforce a strictly $\le 2.0\text{m}$ operational zone, discarding far-field background passersby[cite: 28, 53].

STAGE 02

Quality Inspection

Computes Laplacian blur variance ($\text{threshold} > 10.0$) and head roll angles ($< 25^\circ$), normalizing lighting via YUV linear luminance scaling[cite: 28, 51].

STAGE 03

2D FFT Anti-Spoofing

Applies 2D Fast Fourier Transform on raw face crops. Screen displays (phones/monitors) exhibit distinct high-frequency lattice peak ratios ($> 52.0$), rejecting spoof attacks[cite: 28, 41].

STAGE 04

Dual Embedding Crop

Crops full-face and top-55% pericircular (eye/eyebrow) Region of Interest (ROI) into parallel feature vectors via deep MobileFaceNet ONNX embeddings[cite: 29, 45, 46].

STAGE 05

Dynamic Score Fusion & Consensus

When a lower-face mask is detected, weights shift to $85\%$ Periocular + $15\%$ Full Face[cite: 45]. Reaching 3-frame consensus triggers instant MQTT door unlock, saving localized snapshots and appending to cloud CSV[cite: 27, 29, 42, 44].

4. Asynchronous IoT Hardware Wiring (ESP32 + MQTT)

Verification results are decoupled from host processing threads via non-blocking asynchronous MQTT dispatches on HiveMQ broker topic attendance/door/command[cite: 23, 50].

anti_spoof.py — Frequency Spectrum Analysis Zero IR Hardware Cost 
# 2D Fast Fourier Transform Screen Replay Attack Detector
import cv2
import numpy as np

def inspect_face_roi(self, raw_face_bgr):
    resized = cv2.resize(raw_face_bgr, (128, 128))
    gray = cv2.cvtColor(resized, cv2.COLOR_BGR2GRAY)
    smoothed = cv2.GaussianBlur(gray, (3, 3), 0)

    # Compute 2D Fourier Transform
    f_transform = np.fft.fft2(smoothed.astype(np.float32))
    f_shift = np.fft.fftshift(f_transform)
    magnitude_spectrum = np.abs(f_shift)

    # Zero out low frequencies (DC component)
    cy, cx = 64, 64
    magnitude_spectrum[cy - 16:cy + 16, cx - 16:cx + 16] = 0.0

    peak_ratio = np.max(magnitude_spectrum) / (np.mean(magnitude_spectrum) + 1e-6)

    # Periodic digital display screen lattice triggers peak spike (> 52.0)
    if peak_ratio > 52.0:
        return True, f"SCREEN_DISPLAY_GRID ({peak_ratio:.1f} > 52.0)"
    return False, "LIVE_REAL_SUBJECT"
face_matcher.py — Adaptive Score Fusion Mask & Niqab Resilience 
def fuse_scores(self, score_full, score_perio, occlusion_state):
    if occlusion_state == "MASK_OCCLUDED":
        # Rely heavily on pericircular eye region when lower face is covered
        fused_score = (0.15 * score_full) + (0.85 * score_perio)
        mode = "PERIOCULAR_FUSED"
    else:
        # Prioritize full face embedding when unobstructed
        fused_score = (0.85 * score_full) + (0.15 * score_perio)
        mode = "FULL_FACE_PRIMARY"

    return fused_score, mode, score_full, score_perio
